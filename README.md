# jhtest
江湖主官网测试版

# 项目介绍
这是**江湖公司**的官方首页静态网页，纯前端单页面实现，不需要后端服务器，直接浏览器打开 HTML 文件即可预览运行。
包含功能：

- 顶部导航栏：首页、公司简介、旗下应用、公司历史
- 首页 Hero 简介区域
- 旗下应用：整齐对齐卡片布局，自带跳转按钮（链接集中配置）
- 公司历史：时间线展示
- 深色 / 浅色主题一键切换，主题偏好自动保存在本地浏览器
- 页脚：GitHub 入口、版权声明信息
-
- # 特性
- 响应式：电脑、手机都能正常显示
- 明暗主题切换，本地存储记住上次选择
- 平滑滚动跳转各个板块
- 卡片自动对齐，布局整齐
- 干净简约风格，加载速度快
